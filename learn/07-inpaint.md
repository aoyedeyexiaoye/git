# 蒙版重绘（inpaint）实测（笔记 07）

> 学习日期：2026-10-25 · 本机实测（SD 在 127.0.0.1:7860，darkSushiMix）
> 方法：同一张蓝鲸底图，只改「蒙版范围 / denoising / 负面词」，共 3 组

## 一、核心 API 形状（A1111 /sdapi/v1/img2img）

```json
{
  "init_images": ["<base64>"],
  "mask": "<base64 PNG，白色=重绘区>",
  "prompt": "只描述要在蒙版区内出现的东西",
  "denoising_strength": 0.65,
  "inpainting_fill": 0,        // 0 填充原图 1 保留原图(噪声) 2 噪声 3 空潜空间
  "mask_blur": 8,              // 边缘羽化，接缝硬就加大
  "inpaint_full_res": true,    // 只按原分辨率重绘蒙版区
  "inpaint_full_res_padding": 32
}
```

CLI 已支持（`sdtool.py img --mask-box x,y,w,h`），蒙版用 Pillow 现场画黑底白块。

## 二、三组实测结果

| 组 | 蒙版框 | denoising | 结果 | 判断 |
|---|---|---|---|---|
| A | 150,40,220,140（偏大） | 0.55 | 出现一团"纱帽"状糊块，形状不成 | ❌ 力度不够 + 范围太大 |
| B | 150,40,220,140（同上） | 0.75 | **帽子出来了，但顺带幻觉出一张人脸** | ⚠️ 能出物，但会凭空加主体 |
| C | 196,52,120,86（收紧）+ 负面词加 `person, face, human, anime girl` | 0.65 | 帽子只剩一点黄影，蒙版边缘留下淡灰方块痕迹 | ❌ 太紧 + 羽化不足 |

**整图 SSIM 对照**（B 组 vs 原图）：**0.9327**
对比上一轮整图 img2img 在 denoising 0.75 时的 SSIM **0.712** —— 证明蒙版重绘确实保护了蒙版外区域。
> 换句话说：**0.75 的高强度 + 只改 1/10 面积**，仍能保住 93% 的整体相似度。

## 三、从失败里提炼的规则

1. **蒙版要贴住目标，但别刚好卡死**：留 10~20% 余量给模型理解上下文，太紧（C 组）帽子长不出来
2. **加新物体用 0.7~0.85**：低于 0.6 只会把原内容"糊一层"，出不了新东西（A 组）
3. **高 denoise + 大蒙版 = 幻觉温床**：B 组那张脸就是因为空白区域太大，模型自由发挥
4. **负面词要防"人"**：卡通角色场景里 `person, face, human` 三件套必加
5. **`mask_blur` 别太小**：6 会留出方块边（C 组可见），一般 8~16
6. **卡通平涂角色加配饰，inpaint 不是最优解**：直接在文生图提示词里写 `wearing a yellow beanie` 更可控——inpaint 更适合修瑕、换背景、去杂物

## 四、可复用判断表

| 任务 | 手法 | 建议参数 |
|---|---|---|
| 去掉杂物/水印 | inpaint | denoise 0.5~0.6，蒙版略大于杂物 |
| 换背景 | inpaint（蒙版=四周） | denoise 0.7~0.8，blur 12 |
| 修手/修脸 | inpaint | denoise 0.4~0.5，blur 4~8 |
| 给角色加配饰 | **优先 txt2img** | 写进提示词；实在要 inpaint 用 0.8+ 且负面词防人 |
| 局部改颜色 | inpaint | denoise 0.6~0.7，fill=1（保留原图） |

## 五、踩坑

28. `inpainting_fill` 的含义容易搞反：0=填充原图内容，1=保留原图(作为噪声起点)，2=噪声，3=空潜空间
29. 蒙版必须是**白=重绘**；画反了会得到"反相修复"，看起来像蒙版外被改
30. `inpaint_full_res=true` 时 `padding` 太小，接缝处上下文不足 → 边缘断层；给 32~64
31. 蒙版框坐标是**原图像素**，不是归一化；用错尺度会得到完全错位的方块
