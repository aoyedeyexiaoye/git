# SD 出图参数体系（笔记 03）

> 学习日期：2026-10-25 · 来源：本机 `E:\AI\Deepseek1\sd-webui`（A1111）源码实测
> 目标：把「调哪个参数 → 画面怎么变」变成可查表，不再凭感觉试

## 一、默认值（源码实测，不是印象）

`modules/processing.py` 的 `StableDiffusionProcessing` 默认值：

| 参数 | 默认 | 备注 |
|---|---|---|
| `steps` | **50** | API 默认；WebUI 界面默认 20 |
| `cfg_scale` | **7.0** | 提示词贴合度 |
| `width` / `height` | 512 / 512 | 8 的倍数 |
| `seed` | -1 | -1 = 随机 |
| `sampler_name` | None | 未指定时用界面当前选择 |
| `denoising_strength` | None | img2img 未指定时按 0.75 |
| `eta` | None | 仅 ancestral 系采样器有意义 |

`modules/shared_options.py`：

| 参数 | 默认 | 说明 |
|---|---|---|
| `CLIP_stop_at_last_layers` | **1** | 即 clip skip；2 = 跳过最后一层（动漫模型常配 2） |
| `sd_vae` | **Automatic** | Automatic = 用与 checkpoint 同名的 VAE |
| `eta_ancestral` | 1.0 | k-diffusion ancestral 采样的噪声量 |

## 二、采样器：本质是「求稳」还是「求变」

源码 `samplers_k_diffusion` 里实测到的名字与特性：

| 采样器 | 特点 | 适合 |
|---|---|---|
| `Euler a` | ancestral，**每步注入噪声**（`uses_ensd`），多样性高、收敛快 | 打草稿、试构图、要"活"的画面 |
| `DPM++ 2M` | 确定性强，配 **Karras** 调度默认，细节稳 | 成品图、需要同 seed 稳定复现 |
| `DPM++ 2M Karras` | 上者的调度变体，暗部更干净 | 通用首选 |
| `UniPC` | 少步数（15-20）也能出结构 | 快速批量 |

**经验规则**：同 seed 换采样器，画面结构会变；只改 steps/CFG 则大体保持。

## 三、CFG：提示词"话语权"

| 区间 | 效果 | 风险 |
|---|---|---|
| 3~5 | 更自由、更艺术 | 不听话 |
| 6~8 | 平衡（**默认 7**） | —— |
| 9~12 | 更贴提示词、对比强 | 发灰、畸变、塑料感 |
| >13 | 过饱和、烧图 | 基本不可用 |

CFG 拉高不等于变好；风格不对先查模型和提示词，别先动 CFG。

## 四、denoising（仅 img2img / 蒙版重绘）

| 范围 | 含义 | 用法 |
|---|---|---|
| 0.20~0.35 | 微调：上色、锐化、去噪 | 保原图 |
| **0.40~0.55** | 保画风保构图，换掉细节 | 图生图**默认起步** |
| 0.60~0.75 | 明显改造，原味尚存 | 换姿势/换风格 |
| 0.80~1.00 | 基本重画，只剩构图灵感 | 别指望像原图 |

> 蒙版重绘（inpaint）里 0.4-0.55 修瑕、0.65-0.8 换内容。

## 五、步数

- 20-28 是收益区；30 以上边际收益很小
- 采样器不同，最佳步数不同（UniPC 15-20 就够，Euler a 20-25）
- **步数不足**表现为结构没成形、糊；**步数够但画面脏**是 CFG/负面词问题

## 六、8GB 显存（RTX 4060 Laptop）的硬约束

| 需求 | 做法 |
|---|---|
| 512×512 / 512×768 | 直接跑，安全 |
| 768×1024 以上 | 开 hires fix（scale 1.5~2，denoising 0.5）而不是一步到位 |
| 蒙版重绘大图 | `inpaintFullRes` + padding 32~64 |
| 爆显存 | 先降分辨率，再上 `--medvram`；别急着换模型 |

## 七、决策表（拿到需求怎么配）

| 需求 | 采样器 | steps | CFG | 其他 |
|---|---|---|---|---|
| 快速试构图 | Euler a | 18-22 | 6.5 | seed=-1 多跑几张 |
| 定稿出图 | DPM++ 2M Karras | 24-28 | 7 | 固定 seed 复现 |
| 提示词强控制（复杂构图） | DPM++ 2M | 26 | 8-9 | 负面词写足 |
| 保画风改内容（图生图） | 同参考图模型 | 24 | 7 | denoising 0.45 |
| 动漫模型 | 任意 | 24 | 7 | **CLIP skip = 2** |

## 八、踩坑

10. `denoising_strength` 传 None → 按 0.75，图生图会"面目全非"，要显式传
11. 只改 CFG 不改提示词 → 越调越糟；**先改提示词，再动 CFG**
12. 换采样器不换 seed → 结果完全不可比，做对比实验要固定 seed
13. VAE 用 `Automatic` 但 checkpoint 没有同名 VAE → 画面发灰，需显式指定
